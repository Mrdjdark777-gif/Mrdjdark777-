# knowledge/system/synonyms

Раздел 5 ТЗ перечисляет эту папку отдельно от `knowledge/system/terminology/`,
но раздел 8-9 не проводит между ними чёткой границы. По факту в Phase 6
термин-специфичные синонимы (русские/английские алиасы конкретных Blender
терминов вроде «булеан» = boolean) легли в `Term.aliases` /
`Term.english_aliases` (`knowledge/terminology.py`) — отдельная плоская
таблица синонимов оказалась бы дублированием тех же данных.

Эта папка остаётся зарезервированной под то, что действительно НЕ про
конкретный термин: общие русскоязычные перефразировки вопросов (не «Boolean»
= «булеан», а «как сделать» = «каким образом выполнить» и т.п.) — если
такая нормализация понадобится Intent Engine (Phase 8, раздел 11 ТЗ).
Пустая до тех пор, пока не появится конкретная задача, которая её требует.

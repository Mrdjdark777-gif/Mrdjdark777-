# True Thrills 0.9 — начать здесь

Весь контент бесплатный; поддержка автора — только добровольный донат.

1. Прочитай docs/RELEASE-0.9-RU.md: что изменено и что ещё нужно проверить.
2. Обнови существующий сервер по docs/OPERATIONS-0.9-RU.md. Команды PowerShell и скрипт scripts/TrueThrills-Server.ps1 включены.
3. Установи APK/EXE 0.9 из зелёной сборки на ветке claude/read-link-content-h18psv (Actions → Build Android APK / Build Windows EXE). Сохрани прежний ключ подписи APK.
4. В настройках автора сохрани свою HTTPS-ссылку для доната. Блок появится на главной и во время эфира.
5. Проверь эфир → завершение передачи → готовая запись в подкастах → прослушивание при выключенном ПК. Во время самого эфира ПК нужен как источник звука.
6. Скачай приватную резервную копию на ПК и проверь восстановление.

Для Claude: docs/PROJECT-CONTEXT.md. Рабочая ветка — claude/read-link-content-h18psv; PR codex/stabilize-0.8 (№3) влит в неё вручную и закрыт. Не накатывай старые документы поверх свежего кода. Не объявляй реальные телефонные тесты выполненными по результату mock/CI.

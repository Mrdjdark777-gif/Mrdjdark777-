# True Thrills — что делать владельцу

Версия для проверки: 0.8.0, 9 сентября 2026. Код сохранён в GitHub, ветка `codex/stabilize-0.8`. Это ещё не подтверждение, что сервер уже обновлён.

## Сначала сервер

Остановить эфир, сохранить базу/аудио и `.env`, применить проверенное обновление и миграцию, проверить https://truethrills.com/api/health. Подробные команды — [обслуживание сервера](docs/OPERATIONS-0.8-RU.md). Передать этот документ Claude Code допустимо; отправлять пароли в чат не нужно.

Без миграции 0005 новый веб-интерфейс нельзя считать установленным. Сборка APK сама по себе не меняет сервер.

## Затем Android

В GitHub → Actions → успешный `Build Android APK` → `TrueThrills-Android-apk`. Распаковать ZIP и установить APK поверх старого приложения. Сохранён прежний ключ подписи; если телефон сообщает несовместимую подпись, не удалять приложение, а проверить, какой APK скачан.

Открыть подкаст, убедиться, что показана длительность и двигается ползунок. Проверить скорость, таймер сна и возобновление. Затем заблокировать телефон на 30 минут и управлять воспроизведением с экрана блокировки.

В настройках True Thrills включить уведомления, разрешить их в Android, нажать проверку. Опубликовать тестовую запись и начать эфир с ПК. Нажатие на push должно открывать нужный материал. Если Android блокирует уведомления, приложение показывает это и предлагает открыть настройки телефона.

Прямой эфир проверить отдельно: Wi-Fi, мобильная сеть, блокировка экрана. Нативный фон добавлен для подкастов; надёжность фонового эфира пока не подтверждена.

## Windows и звук

GitHub → Actions → успешный `Build Windows EXE` → `TrueThrills-Windows-exe`. В ZIP находится установщик 0.8.0. После установки проверить иконку, вход паролем автора и микрофон.

Твоя рабочая цепочка сохраняется: SM7B → ART → Komplete → FL Studio. FL Studio выводит готовый стереомикс в CABLE Input, True Thrills принимает CABLE Output в режиме FL Studio/стерео. Наушники в Komplete, INPUT/HOST к HOST, Windows направляет прослушивание CABLE Output на Komplete 1/2.

Компрессор/эквалайзер/шумоподавление голоса ставить на его Mixer Insert. Музыка — на другом Insert, sidechain-компрессор от голоса. Master Stereo separation — по центру. [Полная памятка](docs/RELEASE-0.8-RU.md).

## Что дальше

После проверки телефона включить автоматические копии, сохранить приватную копию на ПК и проверить восстановление. Затем настроить TURN на существующем VPS и проверить разные сети. Начать с небольшой аудитории в пределах 8 слушателей.

Кнопка поддержки уже предусмотрена: добавить HTTPS-ссылку на свою страницу донатов в настройках автора. Автоматическая проверка платежа и закрытые материалы — отдельный будущий этап после выбора провайдера и модели доступа.

Точка продолжения для дальнейшей разработки: [PROJECT-CONTEXT.md](docs/PROJECT-CONTEXT.md). Полный перечень изменений и оставшихся проверок: [RELEASE-0.8-RU.md](docs/RELEASE-0.8-RU.md).

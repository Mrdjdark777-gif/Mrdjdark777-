## Пользователь и рабочая звуковая цепочка

Дима, True Thrills. Windows, SM7B → ART TubeMP Studio V3 → Komplete Audio 6 MK2. FL Studio обрабатывает голос и музыку, FL Studio ASIO input Komplete / output CABLE Input; True Thrills принимает CABLE Output. Музыка на отдельном Mixer Insert, Fruity Limiter COMP получает sidechain с голоса. Наушники в Komplete, INPUT/HOST к HOST; Windows «Прослушивать CABLE Output» направлено на Komplete 1/2. Эта схема подтверждена владельцем в прежней версии.

При добавлении стереовхода True Thrills Stereo separation Master FL возвращается по центру. Сведение Master в моно требуется только для прежнего режима захвата одного канала. Не перерисовывать прозрачный оригинальный логотип и не подкладывать чёрный фон.

## Приоритеты

1. Домен и HTTPS: реальный микрофон и Web Push требуют защищённого контекста. Владелец намерен купить домен; имя ещё не передано.
2. Сохранение настроек FL Studio, стерео, понятная проверка сигнала.
3. Push об эфирах, подкастах и историях, включая закрытое приложение/экран блокировки. Android APK теперь получает уведомления через нативный Firebase Cloud Messaging (не Web Push через Chrome) — см. «Push через Firebase» в RELEASE-0.5-RU.md. Требует пересборки APK через Gradle-сборку в GitHub Actions и секретов `GOOGLE_SERVICES_JSON_BASE64`/`FIREBASE_SERVICE_ACCOUNT_FILE`; на реальном телефоне ещё не проверено.
4. Непрерывное фоновое аудио: сначала устранение подтверждённых причин обрыва, затем нативный media service и проверка на реальном телефоне. Не обещать гарантии по одному серверному тесту.
5. Заработок: Boosty/внешняя ссылка уже предусмотрена; будущий закрытый контент должен работать с новой моделью слушателя. Автоматические платежи, цена, условия и ключи платёжного провайдера ещё не определены. Не выдавать простой переход по ссылке за проверку оплаты.
6. Пересборка Windows/Android под свой домен, резервные копии и небольшой тестовый запуск. Эфиры остаются пилотом до 8 слушателей, STUN без TURN.

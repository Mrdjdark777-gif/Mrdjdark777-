## Статусы

Исходники и автоматические тесты — проверять по Actions на truethrills-app: Build Android APK, Build Windows EXE и Web checks. Web checks больше не перечисляет проверки у себя, а зовёт `npm test` (сборка и 27 наборов) плюс три набора, которым нужен браузер или поднятый сервер. Список проверок один — в package.json; `tests/suite-complete.mjs` роняет прогон, если файл из tests/ не запускает ни один сценарий. Так уже протух `playback-restore.mjs`: он лежал в папке, его никто не звал, и подпись `playPost` разошлась с проверкой незаметно. Перед каждым push прогонять локально то же самое; browser-integration в песочнице без Google Chrome падает на шаге эфира из-за отсутствия AAC — это не сигнал о коде. Сборка пишет одно предупреждение Turbopack «Encountered unexpected file in NFT list» с трассой через app/api/live-stream/route.ts: трассировщик не может статически оценить путь к файлам эфира (id и имя файла приходят из запроса). На результат не влияет — HLS-раздача покрыта live-archive-integration; пометки turbopackIgnore и вынос склейки пути в функцию его не гасят, проверено. Сборка APK запускается только на ветке truethrills-app или вручную: на других ветках Java не компилируется в CI вовсе, и правку нативного кода нужно проверять запуском Build Android APK через workflow_dispatch. Реальный VPS/Windows/Android в этой среде недоступны. Нельзя объявлять установленным или прошедшим блокировку то, что лишь собрано в CI.

решений владелец отменил, увидев их на живом сайте. Эти отмены сильнее листа.

  достижима с клавиатуры, потому что долгое нажатие клавиатуре недоступно.

  эфира недостижим, когда эфир не идёт.
- Кадром главной распоряжается автор («Поставить в кадр главной»), а не только
  дата публикации.

## Дальше

0. Принять design/six-screens: живые проверки из RELEASE-0.9.2-RU.md, затем влить в truethrills-app и выложить. Миграции 0009 и 0010 применяет update-safe.sh; после обновления дать воркеру посчитать пики для существующих выпусков.
1. Сверить ветки и текущую версию VPS. Обновить безопасным скриптом с копией до миграций 0005/0006.
2. Установить подписанный APK 0.9 и Windows 0.9; проверить донат с настоящим URL.
3. Пройти 30–60 минут подкаста и эфира с блокировкой, сети, звонок/наушники; исправлять реальные сбои. Звонки/Bluetooth — проверка поведения плеера, не новые функции.
4. Завершить эфир, проверить архив после выключения ПК; скачать и восстановить реальный backup вне VPS.
5. Настроить независимый монитор/оповещение, политику хранения и небольшой пилот. Никаких новых платных функций.

Документы по версиям до 0.9 удалены как устаревшие — полная история осталась в git log. TURN нужен только прежнему WebRTC-пути; новый HLS использует HTTPS. Не менять лимиты на основании предположения о бесконечной мощности сервера.

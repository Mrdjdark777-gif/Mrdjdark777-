## Git и выкладка

- Основная ветка — `design/six-screens`. Сервер обновляется с неё **только перемоткой вперёд**: историю этой ветки не переписывать никогда.
- Работа идёт в ветке сессии. Отправка — `git push -u origin HEAD:design/six-screens`.
- Каждая отправка проходит веб-проверки на GitHub (`web-checks.yml`, около 40 минут).
  - Состояние смотреть: `gh api "repos/Mrdjdark777-gif/Mrdjdark777-/actions/runs?head_sha=<sha>"`.
  - Журналы падений: инструмент `mcp__github__get_job_logs`.
- Подпись коммитов — как в последних коммитах: строки `Co-Authored-By` и `Claude-Session` в конце.
- Через доступ сеанса GitHub отдаёт 403 на смену ветки по умолчанию, на удаление и переименование веток и на теги. Это делает владелец в веб-интерфейсе.

### Команда обновления сервера

Её запускает владелец в PowerShell на своём ПК:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force; $f=$null; foreach($r in 'D:\','C:\Users','C:\'){ if(-not $f){ $f=Get-ChildItem $r -Recurse -Filter TrueThrills-Obnovit.ps1 -Force -ErrorAction SilentlyContinue | Select-Object -First 1 } }; if($f){ & $f.FullName } else { Write-Host 'Не нашёл' -ForegroundColor Red }
```

- Признак успеха — строка «Сборка совпадает с кодом: <7 знаков коммита>».
- Его программа на ПК — старая копия из архива. Она ходит на сервер по адресам `scripts/update-safe.sh`, `scripts/backup-data.mjs`, `scripts/verify-backup.mjs`. Поэтому переходники в `scripts/` трогать нельзя.

## Как проверять перед отправкой

- `npm test` = сборка + `test:guards` + `test:unit` + `test:integration`.
- Отдельно:
  - `test:browser`, `test:design` (замок телефонной раскладки), `test:live`;
  - `test:reader`, `test:player-enhancements`, `test:home-depth`, `test:phones` (долгий, около часа).
- В песочнице браузер: `TT_BROWSER_EXECUTABLE=/opt/pw-browsers/chromium`.
- Новые проверки — мутацией: сломать, увидеть, что проверка называет поломку словами, вернуть.
- Замок телефона `tests/fixtures/layout-lock.json` переснимать только при намеренной правке телефона, с пометкой в коммите.

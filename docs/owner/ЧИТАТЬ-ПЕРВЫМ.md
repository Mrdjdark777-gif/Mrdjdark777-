# True Thrills — что это и с чего начать

Указатель для того, кто получил проект: программиста, юриста, покупателя.
Владельцу для выкладки — `docs/owner/START-HERE-RU.md`.
Помощнику, который продолжает работу вместо прежнего, — `docs/owner/ПЕРЕДАЧА-ChatGPT.md`:
там сказано, как велась работа и как применяются правки.

**True Thrills** — самостоятельная площадка для подкастов, историй, видео и
прямых эфиров. Три части: сайт и приложение (Next.js на собственном сервере),
приложение слушателя для Android, студия автора для Windows. Весь контент
бесплатный, поддержка только добровольная.

Запуск:

```bash
npm ci
npm run lint
npm test          # сборка и 40 наборов проверок; нужны ffmpeg и JDK
npm run dev
```

Браузерные наборы и аудит экранов запускаются отдельно:
`npm run test:browser`, `npm run test:design`, `npm run test:live`,
`npm run test:reader`, `npm run test:player-enhancements`,
`npm run test:home-depth`, `npm run test:phones`.

Устройство каталогов:

- `app/`, `components/`, `hooks/`, `lib/` — сайт и приложение (Next.js 16, React 19, TypeScript);
- `db/`, `drizzle/` — схема SQLite и миграции, последняя 0011;
- `android/` — приложение слушателя: Java, WebView, Media3, Firebase;
- `desktop/` — студия автора: C++ и WebView2;
- `server/` — обслуживание сервера: обновление с откатом, бэкапы с проверкой, уборка, мониторинг, воркер эфира;
- `tools/windows/` — программы владельца для Windows (обновление, копия, восстановление); `tools/dev/` — иконки, опись лицензий, выкладка APK;
- `scripts/` — только переходники со старых адресов (их зовут таймеры сервера и старая программа обновления); править в `server/` и `tools/`;
- `tests/` — проверки по папкам: `unit/`, `integration/`, `browser/`, `sweeps/`, `guards/`, данные в `fixtures/`. `tests/guards/suite-complete.mjs` следит, чтобы ни одна не осталась без запуска и лежала в своей папке;
- `docs/` — документы по разделам: `owner/`, `releases/`, `operations/`, `audits/`, `legal/`, `design/`. Полная карта — `README.md`;
- `workers/`, `public/`, `vendor/` — воркер эфира, статика, сторонний CSS.

| Вопрос | Документ |

Что важно знать сразу:

- **Правообладатель — Dumitru Paiul.** Имя стоит только в документах:
  `LICENSE`, `docs/legal/RIGHTS-RU.md` и этот файл. В самом продукте его нет
  намеренно — там название канала. Автоматическая проверка следит за обеими
  сторонами: чтобы имя не пропало из документов и не вернулось в код.
- **Лицензия закрытая: все права сохранены.** Доступ к коду сам по себе
  никаких прав не передаёт — получение этого архива в том числе. Разрешения
  выдаются только письменно.
- **Из 507 сторонних пакетов 167 уезжают в поставку.** Подавляющее
  большинство под разрешительными лицензиями. Разбора требуют четыре, они
  названы поимённо в `docs/legal/LICENSES-RU.md`.
- **Персональных данных система собирает мало.** Регистрации нет, имён,
  почты и телефонов не спрашивают нигде, отметки прослушивания не покидают
  устройство, аналитики и сторонних трекеров в коде нет. IP-адрес нигде не
  хранится в открытом виде. Подробно и со сроками хранения — в
  `docs/legal/PRIVACY-DATA-RU.md`, там же список того, чего пока нет: политики
  конфиденциальности, формулировки согласия, процедуры на запрос об удалении.

Опись лицензий собрана скриптом и сверяется автоматической проверкой:
устареть незаметно она не может.

## Чего в проекте нет и не должно быть

- `.env` с настоящими настройками сервера — есть только образец
  `.env.example` с пустыми значениями;
- приватный ключ SSH к серверу;
- `firebase-service-account.json` и `google-services.json`;
- ключ подписи приложения Android;
- `node_modules/`, `.next/`, `data/` — ставятся и создаются заново.

## Материал автора

Обложки, звук, записи эфиров и тексты публикаций в репозиторий не входят: они
лежат на сервере в каталоге данных. Картинки в `tests/fixtures/` — служебные,
только для автоматических проверок вёрстки.

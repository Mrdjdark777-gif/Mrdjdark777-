# True Thrills Plugin System v1

## Цель

True Thrills становится расширяемой платформой без загрузки исполняемого кода в Android. Плагины выполняются на сервере; Android, Web и Windows Studio остаются клиентами одного API.

## Что входит в v1

- `PluginHost` — регистрация, включение/выключение и вызов инструментов.
- `PluginManifest` — стабильный контракт плагина: id, версия, API, протокол, разрешения, tools и events.
- `Permission Engine` — плагин не может публиковать события или объявлять tool с правом, которого нет в manifest.
- `Event Bus` — плагины общаются событиями, не импортируя друг друга.
- `GET /api/plugins` — только владелец видит установленные плагины и их возможности.
- Первый встроенный плагин `truethrills.notifications` адаптирует существующую очередь push и не меняет её текущий публичный API.

## Граница Core / Plugins

Остаются Core: авторизация и владелец, модель контента, база и миграции, локальное media storage, live lifecycle, плеер, Plugin Host, permission/event infrastructure и будущий secrets vault.

Выносятся в плагины поэтапно: push/уведомления, AI-транскрипция, перевод, аналитика, публикация на внешние площадки, сторонние storage providers и автоматизации.

## Безопасность

- В Android не загружаются `.dex`, `.jar`, `.so` или другой исполняемый plugin-код.
- Внешние интеграции будут выполняться на сервере.
- Права задаются manifest-ом по принципу минимально необходимых.
- Деструктивные tools помечаются `destructive` и не должны становиться публичным анонимным API.
- Секреты провайдеров не передаются клиентам и не хранятся в manifest.

## Следующая фаза

v2 добавит серверный MCP Client: подключение удалённого MCP server по HTTPS, OAuth/secret storage, health-check, enable/disable, registry установленных подключений и UI раздела Plugins. MCP не эмулируется в v1: поле `protocol: 'mcp'` зарезервировано контрактом, но remote runtime ещё не включён.

# Редизайн сайта для ПК (октябрь 2026)

Основа — пакет «TrueThrills-Desktop-Redesign», который владелец передал
11 октября: документ с заданием и CSS-заготовка. Пакет — задание, а не
готовый код: классы заготовки (`tt-*`, `data-tt-desktop`) в проект не
переносились, её правила разложены по настоящим компонентам сайта для ПК
(`components/studio/desk-*.tsx`, `components/studio/desk.css`).

Здесь записано, что из пакета принято, что владелец решил иначе и в каком
порядке идёт работа. Решения владельца не переигрывать без его слова.

## Решения владельца (12 октября)

| Вопрос | Пакет предлагал | Решение владельца |
|---|---|---|
| Поддержка | блок «Поддержать True Thrills» внизу главной и бьющееся сердечко на главной, в плеере и в эфире | **не возвращать**: остаётся только сердечко вверху справа, без анимации (решение 9 октября в силе) |
| Каталог на главной | один блок «Новое в True Thrills» с переключателями вместо полок по разделам | **принято** |
| Размер карточек на главной | всегда 220–260 px, ряд можно докручивать | **ряд целиком на первом экране**: карточки растут, пока ряд помещается в окно (на 1920×945 — около 175 px, на высоких окнах — до 260 px) |
| Порядок работы | одним пакетом | **тремя заходами**, после каждого — проверки, снимки и обновление сервера |

## Правки владельца после первого захода (13 октября, по снимку с его монитора)

| Замечание владельца | Что сделано |
|---|---|
| «Когда я включаю плеер, иконки становятся значительно меньше» | размер плиток считается без плеера; с плеером страница докручивается на его высоту |
| Переключатели Все / Аудио / Видео / Истории / Архив справа от «Новое» — «зачем, если они есть сбоку» | убраны |

| Разделы «переместить по центру экрана, чтоб были прям видны» | разделы — в верхней строке по центру (выбор владельца из трёх вариантов); слева остались знак канала, приложение с QR и соцсети |
| В разделах крупный выпуск «на пол экрана» | обложка крупного выпуска меньше, своей пропорции; заголовок мельче |
| «Новое» — по центру, не больше 7–8, без карусели и стрелок | один ряд по центру, не больше восьми плиток; сколько влезает в ширину — столько и видно |

Обложка первого экрана не менялась: 4:1, 2400×600, во всю ширину. Владелец
одобрил её 9 октября; пакет тоже просит её сохранить.

## Заходы

1. **Главная, разделы, карточки, фон** — сделано 12 октября, поправлено 13 октября (см. выше):
   - один ряд «Новое в True Thrills» вместо полок по разделам;
   - каждый выпуск в ряду один раз, выпуск с обложки не повторяется;
   - карточка — цельная поверхность с тихой светлой кромкой и мягкой тенью, под мышью поднимается на 3 px. Ярлык типа — по центру сверху;
   - «Поделиться» у каждой карточки — отдельная кнопка рядом с длительностью, видна всегда, не только под мышью;
   - запись эфира без выбранного типа подписана «Запись эфира», а не «Подкаст»;
   - поиск показывает все найденные выпуски, а не один ряд;
   - на ПК нет фона-сетки в разделах.
2. **Развёрнутый плеер с очередью** — следующий заход.
3. **Эфир** — после плеера.

## Что из пакета не принято и почему

- Шрифт Literata для заголовков: роль «серьёзного serif» уже занимает Lora (см. `app/layout.tsx`). Её выбрали за румынские ș и ț, и замена сменила бы вид и телефона.
- Ширина содержимого 1840 px: осталась 1680 px. Это касается только мониторов шире 1944 px, а у них обложка уже стоит по центру карточкой.

## Проверки

- `tests/browser/desk-layout.mjs` — каркас ПК, разделы в верхней строке, первый экран, ряд «Новое» (по центру, до восьми, тот же размер с плеером), «Поделиться» у карточек, вход для автора только в программе, размер крупного выпуска, отсутствие фона-сетки. Новые проверки прогнаны мутацией.
- `tests/browser/surfaces.mjs` — разграничение поверхностей.
- `tests/sweeps/design-preview.mjs` — замок телефонной раскладки: работа над ПК его не двигает.

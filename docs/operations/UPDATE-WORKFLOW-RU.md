# Обновление с Windows — согласованный порядок

28 сентября 2026. Выдавать владельцу готовый архив и один блок запуска PowerShell. Код вручную не редактировать.

- Основа: последняя принятая владельцем версия; сохранять изменения Claude.
- На Windows для изолированных проверок читалки использовать npm ci --ignore-scripts --include=optional. Серверный better-sqlite3 для этих тестов не нужен. Не требовать Visual Studio из-за Node 24.
- На сервере npm ci остаётся штатным, с установочными скриптами.
- GitHub push выполнять через credential.helper=manager, сбрасывая предыдущий список помощников для данной команды. Использовать сохранённую авторизацию; повторный вход — только если GitHub отклонил доступ.
- Перед заменой сверять контрольные суммы целевых файлов. Новые неизвестные правки не перетирать.
- Только обычный push, без force. Не добавлять весь каталог через git add -A.
- Сервер обновлять штатным TrueThrills-Server.ps1 с ExpectedCommit. Нужны строки «Выложен коммит» и «Сборка совпадает с кодом».
- При сбое push сохранить готовый локальный коммит и продолжать из той же папки; не заставлять владельца повторять все проверки.
- Ключ SSH остаётся на ПК. Для веб-правок новый APK не требуется.
- Всегда отдельно указывать проверки на Windows/телефоне и проверки в тестовой среде.

# Расходы, лимиты и защита (15 октября 2026)

Владелец: «я пока не буду тратить деньги на это приложение… расходов не
должно быть вообще, и если что-то начнётся — я должен сразу знать». Здесь —
что может стоить денег, что поставлено в коде и что нужно сделать руками в
Oracle и Telegram.

## Что может стоить денег

| Что | Сколько стоит | Почему |
|---|---|---|
| Сервер Oracle Cloud (Ampere, Always Free) | 0 | бесплатный тариф |
| Исходящий трафик Oracle | 0 до 10 ТБ в месяц | дальше платно, **но только если аккаунт переведён на оплату (Pay As You Go)** |
| Уведомления Android (Firebase Cloud Messaging) | 0 | у FCM нет платы за сообщения |
| GitHub, код и проверки | 0 | публичный репозиторий |
| Telegram-бот для уведомлений | 0 | |
| Домен truethrills.com | раз в год у регистратора | единственная плановая трата |

Главное: **аккаунт Oracle на бесплатном тарифе (Free Tier) списать деньги не
может вообще** — платные ресурсы на нём просто не создаются. Счёт возможен,
только если аккаунт переведён на оплату. Это и есть настоящий «жёсткий
лимит», и проверить его может только владелец (ниже).

Сколько это в слушателях: 10 ТБ — примерно 4 миллиона минут звука в 320
кбит/с за месяц, то есть десятки тысяч часов. Для канала это очень много;
опасность не в слушателях, а в роботе, который выкачивает выпуски по кругу.

## Что сделано в коде

1. **Счётчик трафика за месяц** — `server/traffic.mjs`, считает монитор
   (`server/monitor.mjs`, раз в 5 минут) по `/proc/net/dev`. Предел —
   `TRAFFIC_MONTH_LIMIT_GB` в `.env`, по умолчанию **8000 ГБ** (80 % бесплатных
   10 ТБ, с запасом). На 50 % и 80 % — уведомление, по одному разу в месяц.
2. **Стоп-кран** — на пределе монитор кладёт `data/operations/traffic-stop`,
   и слушатели до 1-го числа не получают звук выпусков и эфир
   (`lib/traffic-pause.ts`, ответ 503). Автор работает как обычно. С новым
   месяцем флаг снимается сам; поднять предел — изменить
   `TRAFFIC_MONTH_LIMIT_GB`.
3. **Лимиты на один IP в nginx** — 30 запросов в секунду с запасом 200 и 60
   соединений разом; лишнее получает 429. Робот не сможет выкачивать выпуски
   в сотню потоков. Версия nginx в ответах скрыта.
4. **Уведомления в Telegram** — `server/notify.mjs`: сбой сайта, мало места,
   сертификат, резервные копии, воркер эфира, трафик. «Всё снова в порядке»
   приходит одним сообщением, когда беда прошла.

## Защита

Было и раньше: HTTPS; вход автора по паролю с ограничением попыток; cookie
входа HttpOnly и SameSite; проверка источника запросов; пределы размера
запросов; проверка содержимого загрузок; приложение работает от отдельного
пользователя без прав администратора; данные закрыты (700), `.env` — 640;
копии шифруются паролем до выхода с сервера.

Добавлено 15 октября:

- **заголовки безопасности** на всех ответах (`next.config.ts`): сайт нельзя
  встроить в чужую страницу, браузер не угадывает тип файлов, HTTPS
  закреплён на год (HSTS), камера и геолокация выключены;
- **SSH только по ключу**, вход root закрыт (ставится, только если на сервере
  уже есть ключ — иначе владелец остался бы снаружи);
- **fail2ban** — адрес, который подбирает вход по SSH или долбит сайт сверх
  лимита, блокируется на час;
- **автоматические обновления безопасности Ubuntu**;
- **ключ Firebase на сервере** — 640, читает только сервис.

Всё это ставит `server/install-operations.sh` при обычном обновлении. Каждый
шаг проверяется (`nginx -t`, `sshd -t`) и при сбое откатывается, не ломая
сайт. На настоящем сервере это ещё не запускалось: проверено в песочнице с
заглушками вместо nginx, sshd и apt.

## Ключи

Репозиторий публичный. Проверено 15 октября: **ни в коде, ни во всей истории
git нет ключей, паролей, файла подписи APK и ключа Firebase**. `.gitignore`
дополнен, чтобы такие файлы не попали туда и случайно.

Где что должно лежать:

| Ключ | Где | Почему |
|---|---|---|
| `.env` сервера, ключ Firebase | только на сервере | без них сервер не работает; закрыты правами доступа, в копиях — зашифрованы |
| ключ SSH (`D:\True Thrills\Private SSH - Key\…`) | только на твоём ПК + копия на флешке | это вход на сервер |
| ключ подписи APK (`.jks`) и его пароли | только на твоём ПК + копия на флешке | потеряешь — не сможешь обновить приложение; украдут — смогут выпустить подделку под твоим именем |

Что сделать на ПК (один раз):

1. Включить **BitLocker** на диске D: (Windows Pro: Пуск → «Управление
   BitLocker»). Если Windows Home — бесплатный **VeraCrypt**: создать
   зашифрованный контейнер и перенести туда папку с ключами.
2. Пароли от ключа APK, Oracle, GitHub, почты — в менеджер паролей
   (например, бесплатный Bitwarden), а не в текстовый файл.
3. Копия ключей — на флешке, которая хранится дома, отдельно от ПК.
4. Никогда не пересылать ключи через мессенджеры, почту и облака — ни себе,
   ни другим.

## Что сделать владельцу руками

### 1. Проверить, что аккаунт Oracle бесплатный

Oracle Cloud → правый верхний угол, профиль → **Tenancy** или раздел
**Billing & Cost Management → Upgrade and Manage Payment**. Если там
предлагают «Upgrade your account» — аккаунт бесплатный (Free Tier), денег
списать не могут. Если написано «Pay As You Go» — аккаунт платный: тогда
обязательно шаг 2, а перевод обратно на бесплатный — только через поддержку
Oracle. Названия пунктов меню у Oracle меняются; если не найдёшь — пришли
снимок экрана.

### 2. Оповещение о любой трате на почту

Oracle Cloud → **Billing & Cost Management → Budgets → Create Budget**:
сумма **1 USD** в месяц, правило оповещения — **Actual spend** больше **1 %**,
адрес — твоя почта. Если когда-нибудь появится хоть цент расходов, письмо
придёт в тот же день. Это стоит сделать и на бесплатном аккаунте.

### 3. Уведомления о сервере в Telegram

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя → он пришлёт
   токен.
2. Открой своего нового бота и нажми **«Старт»**.
3. Сначала обнови сервер (новый код должен быть там). Потом на ПК в
   PowerShell — команда работает напрямую через ssh, старая копия программ
   на ПК ей не мешает:

```powershell
$k='D:\True Thrills\Private SSH - Key\ssh-key-2026-09-06.key'; $s=Read-Host -AsSecureString 'Токен бота'; $t=[Runtime.InteropServices.Marshal]::PtrToStringAuto([Runtime.InteropServices.Marshal]::SecureStringToBSTR($s)); $t | ssh -i $k ubuntu@129.152.8.230 'cd /opt/truethrills && sudo node server/set-telegram.mjs'
```

В новой копии программ то же самое делает
`tools/windows/TrueThrills-Server.ps1 -Action Telegram`.

Вставь токен — сервер сам найдёт твой чат и пришлёт пробное сообщение.

# Сторонние компоненты и их лицензии

Собрано из `package-lock.json`, а не из установленного каталога и не по
памяти. Разница принципиальная: опись, снятая с `node_modules`, зафиксировала
43 версии, которых нет в lock, и пакет, поставленный когда-то мимо
зависимостей. Lock — это то, что действительно приедет к другому человеку по
`npm ci`.

Машинный список со всеми 646 пакетами: `docs/third-party-licenses.csv`.
Пересобрать:

```bash
node scripts/license-inventory.mjs --write
```

`tests/licenses.mjs` роняет прогон, если сохранённая опись разошлась с
lock-файлом, — список не может тихо устареть.

Колонка «поставка» в CSV отделяет то, что уезжает на сервер и в приложение
(182 пакета), от инструментов разработки (464). В lock перечислены варианты
под все платформы, поэтому одна и та же библиотека может встречаться
несколько раз — это полнее, чем список для одной машины, и для правовой
проверки так безопаснее. К последним требования
лицензий другие: их никому не передают.

## Что стоит показать юристу отдельно

Остальные лицензии в списке — разрешительные и вопросов обычно не вызывают.
Эти четыре строки — единственные, где условия сложнее «сохрани текст».

**`mediabunny` 1.55.7 — MPL-2.0, уезжает в поставку.**
Разбирает и собирает медиаконтейнеры; используется при записи звука. MPL-2.0
— копилефт на уровне файла: открывать собственный код не требуется, но если
править файлы самой библиотеки, изменения нужно публиковать под MPL. Сейчас
библиотека используется без изменений, как зависимость из реестра.

**Сборки `@img/sharp-libvips-*` и `@img/sharp-win32-*` 1.2.4 —
LGPL-3.0-or-later (у Windows-сборок вместе с Apache-2.0), уезжают в поставку.**
Двоичная сборка libvips; приходит транзитивно вместе с обработкой картинок в
Next.js. В lock их четырнадцать — по одной на платформу, условия у всех одни
и те же. LGPL требует, чтобы у получателя оставалась возможность заменить
библиотеку своей версией, и чтобы исходный код библиотеки был доступен.
Библиотека подключается как отдельный модуль и не изменялась.

**`caniuse-lite` 1.0.30001810 — CC-BY-4.0, уезжает в поставку.**
База данных поддержки браузеров. Условие одно — атрибуция.

**`lightningcss`, `axe-core`, `argparse` — MPL-2.0 и Python-2.0, только
разработка.** В поставку не входят, никому не передаются.

## Не из npm

- **Android.** `androidx.webkit` 1.12.1, `androidx.media3` 1.5.1
  (exoplayer, session, hls) — Apache-2.0. `com.google.firebase:firebase-messaging`
  из firebase-bom 33.7.0 — распространяется по условиям Firebase и Google
  APIs Terms of Service; это сервис Google, а не только библиотека.
- **Windows.** Студия построена на Microsoft Edge WebView2 — условия
  распространения задаёт Microsoft (WebView2 Runtime Distribution Terms).
  Сам код студии — `desktop/client.cpp`, собственный.
- **Шрифты.** Manrope и Lora — SIL Open Font License 1.1, раздаются своим
  сервером через `next/font/google`.
- **`vendor/shadcn-tailwind-4.13.0.css`** — вложенная копия оформления
  shadcn/ui, MIT. Текст лицензии лежит рядом:
  `vendor/shadcn-tailwind-4.13.0.LICENSE.md`.
- **FFmpeg** на сервере не поставляется вместе с продуктом: он ставится из
  репозитория Ubuntu скриптом обслуживания и вызывается как отдельная
  программа. Если продукт когда-нибудь начнут передавать вместе со сборкой
  FFmpeg, условия его лицензии (LGPL или GPL в зависимости от сборки)
  придётся разбирать отдельно.

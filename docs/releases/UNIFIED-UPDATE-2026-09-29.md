## Установка одним действием
Архив содержит source/ — полные исходники единой версии; replacement/ — полные файлы для обновления; Apply-And-Update.ps1 — запуск всех действий с ПК владельца; manifest.json — контрольные суммы.
Скрипт получает актуальную ветку, требует наличие базы d863ce0, проверяет файлы и сохранённые стили Claude, выполняет проверки, создаёт обычный коммит и отправляет его без force. Затем запускает штатное обновление сервера с ExpectedCommit. Так сервер получит и ещё не установленные изменения Claude, и новые доработки за один запуск.
Не копировать source поверх рабочей папки вручную. При неизвестных изменениях скрипт остановится до перезаписи. SSH-ключ остаётся на ПК; серверные секреты в пакет не входят.
Устанавливать вне эфира. Штатный updater делает резервную копию и временно останавливает службы. Ошибка после остановки не означает автоматический откат; сохранить вывод и использовать штатное восстановление.
Успех подтверждается проверкой /api/health и строкой «Сборка совпадает с кодом». Номер коммита искать в интерфейсе не нужно — он намеренно удалён.
Оболочки Android/Windows не менялись; новый APK/EXE для этого обновления не собирался и не требуется при штатной загрузке веб-приложения.
